# 福州软件职业技术学院 · 五年计划指标管理平台操作指南

> 适用版本：2026 年 11 月当前版本  
> 适用对象：平台管理员、校级负责人、建设方向负责人、学院项目负责人
> 说明：本指南按现行 **A 类指标 → 学院 B 任务** 流程编写。历史 A+ 数据仅用于兼容查看，不再新建。

## 一、先了解角色与基本规则

### 1.1 角色分工

| 角色 | 主要工作 | 数据范围 |
| --- | --- | --- |
| 平台管理员 | 建计划、维护指标、分解下发、系统配置、代填代审、目标调整、年度及五年核算 | 全校 |
| 校级负责人 | 查看统计与大屏、审批调整、查看操作日志 | 全校 |
| 建设方向负责人 | 维护本人负责的指标、分解下发、审核填报、初审调整 | 本人负责的 A 及其 B |
| 学院项目负责人 | 查看本学院任务、填报完成值、上传材料、确认接收转入任务 | 本学院 B 任务 |

一个账号可以同时拥有多个角色，系统按权限并集显示功能。看不到某个菜单或按钮时，通常表示当前账号没有对应权限，而不是系统故障。

### 1.2 当前版本的八条重要规则

1. **新任务直接从 A 分解到 B**，不再创建独立 A+。
2. 学院任务下发后**无需确认接收**，符合年度条件即可填报。
3. 学院负责人**不能发起调整**，但可以确认接收其他学院转入的任务。
4. 只能填报**服务器当前自然年份**的数据，历史记录仍可查看。
5. 只有**审核通过**的填报才计入完成值、统计报表和材料库。
6. 已下发指标不能直接修改既有目标；需要变更时走调整审批。
7. 年度核算后该年度锁定；计划归档后整个计划只读。
8. 历史任务只读，不参与新的填报、审核、调整、待办和预警。

## 二、登录与通用操作

### 2.1 登录系统

1. 打开管理员提供的系统地址。
2. 选择以下任一方式：
   - **账号密码登录**：输入工号和密码；
   - **飞书登录**：在已配置飞书集成的环境中，按页面提示完成授权。
3. 登录后进入角色首页：
   - 仅具有学院项目负责人角色的用户进入 **学院工作台**；
   - 其他用户进入 **首页 / 计划列表**。

如提示账号或密码错误，请核对工号；连续失败导致账号暂时受限或密码遗忘时，联系平台管理员处理。

### 2.2 选择当前计划

首页、指标总表、统计报表、大屏、审核中心等页面会围绕“当前计划”工作。

1. 在首页点击目标计划卡片，或从计划入口进入相应页面。
2. 开始操作前，先核对页面中的计划名称和规划周期。
3. 切换计划后，重新检查指标、任务、材料和筛选结果，避免在错误计划下操作。

### 2.3 查询、刷新与返回

- 列表页可按页面提供的指标、学院、状态、年份、关键词等条件筛选。
- 点击 **重置** 可清空普通筛选条件。
- 数据页面会自动刷新；正在编辑时，系统会避免用后台刷新结果覆盖尚未保存的输入。
- 修改重要数据前，如页面提示“数据已被修改”，先刷新并核对最新内容，再重新提交。
- 手机或飞书内置浏览器重点支持 **学院工作台、任务填报、待办与消息**；复杂的指标分解、批量审核建议使用电脑。

## 三、标准业务流程

建议按以下顺序推进：

1. 管理员维护执行单元、用户、角色和基础参数。
2. 管理员新建计划，配置主要建设方向。
3. 管理员或建设方向负责人录入、导入并检查 A 类指标。
4. 将可量化 A 分解为学院 B，指定学院负责人和逐年目标。
5. 预览并下发任务，按计划需要启动执行。
6. 学院负责人填报当前年度完成值并上传佐证材料。
7. 建设方向负责人或管理员审核；通过后自动汇总完成值。
8. 需要变更时，由管理员或建设方向负责人发起调整并完成审批。
9. 管理员执行年度核算、处理补做，规划期结束后执行五年核算。
10. 通过统计报表、大屏、材料库和操作日志进行跟踪与归档。

## 四、平台管理员操作

### 4.1 初始化系统基础数据

进入 **系统管理**，按需完成以下配置。

#### 执行单元

1. 打开 **执行单元** 页签。
2. 点击 **新增执行单元**，填写编码、名称、类型和排序。
3. 根据业务需要设置 **启用状态** 和 **可承接新 B**。
4. 保存后，在任务分解中检查该单元是否可选。

注意：只有“已启用”且“可承接新 B”的单元才能承接新任务。已有历史任务不会因停用而被删除。

#### 用户与角色

1. 打开 **用户与角色** 页签。
2. 点击 **新增用户**，填写姓名、工号、手机号、所属单元和初始密码等信息。
3. 勾选角色；同一人可配置多个角色。
4. 对已有用户可编辑信息、停用账号或重置密码。
5. 将用户设置为指标或任务负责人后，使用对应账号核对可见范围。

#### 主要建设方向与专业群

- 在 **主要建设方向** 中选择计划，新增或编辑方向，可指定具有校级负责人角色的总负责人，并维护 A 指标归属。
- 在 **专业群** 中维护名称、所属学院、负责人和启用状态。
- 指标自身或下属任务下发后，相关方向结构和归属可能锁定，应在下发前核对。

#### 字典、参数与飞书

- **字典**：维护计量单位、材料类型等自定义字典；系统内置枚举只读。
- **参数配置**：按页面说明维护文件限制、预警阈值、提醒天数等参数，保存后在后续操作中生效。
- **飞书集成**：查看配置与回调信息；需要同步时按页面提示执行组织与人员同步。

### 4.2 新建与管理计划

1. 进入 **首页**，点击 **新建计划**。
2. 选择创建方式：
   - **空白新建**：从零搭建指标；
   - **从模板新建**：复用模板中的方向和指标结构；
   - **复制已有计划**：复制已有计划结构，按需选择是否复制分工。
3. 填写计划名称、起止年份、基线年、年度核算截止日等信息。
4. 保存后进入计划，继续维护指标和分工。
5. 准备工作完成后，在 **计划概览** 点击 **启动执行**。

计划卡片菜单还提供复制、另存为模板和归档等能力。复制产生的是新计划，不复制原计划的填报、审核等执行结果。

### 4.3 录入或导入 A 类指标

#### 手工新增或编辑

1. 进入当前计划的 **指标总表**。
2. 点击新增入口，或在目标指标的 **更多** 中选择编辑。
3. 填写指标编号、名称、指标性质、是否可量化、负责人和填写说明。
4. 对可量化指标继续填写：
   - 所属主体、计量类型、统计口径、计量单位；
   - 达成方向、汇总方式、基线值；
   - 五年目标和各年度目标；
   - 佐证材料要求及最少材料数。
5. 保存后，在列表中展开指标，核对目标和学院任务。

不可量化 A 只维护基础信息，不生成学院任务，也不参与填报、审核和完成率统计。

#### Excel 批量导入

1. 在 **指标总表** 下载标准导入模板。
2. 按模板列和示例填写，不随意修改表头。
3. 点击导入并选择文件。
4. 查看预览和逐行校验结果；有错误时按提示修改 Excel 后重新导入。
5. 校验通过后确认导入，并抽查指标数量、目标和负责人。

比率、百分比和增长率数据应按模板示例填写；系统统一按标准比率存储和展示。

### 4.4 分解并下发学院任务

1. 在 **指标总表** 找到可量化 A，点击 **任务分解**。
2. 在弹窗中选择承接学院，为每条 B 指定学院项目负责人。
3. 填写各学院五年目标及逐年目标，并核对材料要求。
4. 点击 **保存草稿**。草稿允许暂时存在合计不足，便于分多次完善。
5. 点击下发预览，检查学院、负责人、逐年目标和校验结果。
6. 确认无误后执行下发。

下发前重点检查：

- INCREMENT、STOCK 等数量型任务，各学院年度合计不得低于指标年度目标，允许超额分配；
- 比率类和是否型不按普通数量简单求和；
- 增量累计型指标自身的各年度目标之和应等于五年总量；
- 每条新 B 都必须有负责人，承接单元必须具备承接资格。

已下发指标允许**追加学院**：已有生效任务保持只读，只保存并下发新增学院的草稿。既有目标变更不能直接覆盖，须走调整审批。

### 4.5 审核填报

管理员可以代审，具体操作见“六、校级审核操作”。管理员代填时必须按页面要求填写代填原因；代审原因按页面标注填写，驳回或核减时仍必须写明审核意见。

### 4.6 年度核算、解锁与补做

进入 **计划概览 → 年度核算管理**。

1. 确认当年填报和审核已处理完毕。
2. 点击目标年度的 **年度核算**。
3. 阅读提示并确认。系统会锁定该年度并生成达标、未达标结果。
4. 在 **年度核算结果** 中查看缺口和待补做记录。
5. 补做工作真实完成后，点击 **确认补做完成**，来源年度同步标记为已补做。

注意：

- 存在待审核填报时，应先审核或撤回，再执行年度核算。
- 年度锁定后，该年度填报、审核、分解和调整均只读。
- 确需修改时点击 **解锁**，填写明确原因并确认；解锁和后续修改都会留痕。
- 计划启动后年度默认激活，但学院仍只能填报当前自然年。

### 4.7 五年核算与归档

1. 确认当前时间已晚于规划结束年份，并且全部年度已核算锁定。
2. 在 **年度核算管理** 点击 **五年核算**。
3. 查看指标总数、达标数和未达标数。
4. 完成所有收尾工作后，再执行 **归档**。

归档后计划只能查看，不能继续填报、审核、调整或修改配置，请在确认前慎重操作。

## 五、建设方向负责人操作

### 5.1 查看负责范围

- 首页只显示与本人负责指标相关的计划。
- 指标总表、审核中心、材料库和调整列表均按本人负责范围过滤。
- 若负责人在指标保存后才调整，重新登录或刷新页面后再核对数据范围。

### 5.2 维护指标与分解任务

建设方向负责人可在本人负责范围内执行指标编辑、任务分解、草稿保存和下发，步骤与管理员相同。不可处理他人负责的指标；已下发目标须通过调整审批变更。

### 5.3 审核学院填报

进入 **审核中心**，按“六、校级审核操作”执行。只有审核通过的数据才进入完成值和统计。

### 5.4 发起和初审调整

- 可对权限范围内的任务发起延期、转移或延期加转移。
- 收到调整初审待办后，核对未完成量、目标年份、接收学院、原因和附件，再决定通过或驳回。
- 具体流程见“七、指标调整操作”。

## 六、学院填报与校级审核操作

### 6.1 学院负责人填报

1. 进入 **学院工作台**。
2. 核对当前计划、年度和本学院任务，可通过状态或关键词筛选。
3. 在目标任务上点击 **填报**。
4. 按统计口径填写本次完成内容：

| 统计口径 | 应填写的内容 |
| --- | --- |
| 增量累计型 | 本次新增数量，不填历年累计总量 |
| 存量时点型 | 当前最新总量 |
| 增长率型 | 当年实际总量，不直接填写增长率 |
| 占比型 | 分子和分母，不直接填写各学院百分比 |
| 直填百分比型 | 百分比、数据来源说明和佐证材料 |
| 是否型 | 是否完成及相关完成信息 |

5. 填写完成情况说明。
6. 上传佐证材料，等待每个文件显示上传完成。
7. 点击 **保存草稿** 暂存，或点击 **提交审核** 正式进入审核。

直填百分比即使未单独设置最少材料数，也必须至少上传一份佐证材料。

### 6.2 撤回、驳回后修改与查看记录

- **审核期间**：填报内容只读；如确需修改且尚未审核，可点击 **撤回**，修改后重新提交。
- **被驳回**：查看审核意见，修改完成值或材料后重新提交。
- **查看历史**：在填报记录或任务详情的提交记录中查看每次提交、审核结果、意见和材料。
- **已达标或年度锁定**：按页面状态只读，不重复提交。

对“越大越好”的指标，提交或审核后年度完成率不能超过 100%；如确需提高目标，应先走目标调整，而不是超额填报。

### 6.3 建设方向负责人或管理员审核

1. 进入 **审核中心**。
2. 使用指标、学院、关键词或提交时间筛选待审记录。
3. 选择一条填报，核对任务、年度、填报值和完成情况说明。
4. 逐份在线预览佐证材料；必要时下载核查。
5. 如需核减，修改认定值。认定值不得大于填报值，核减时必须填写审核意见。
6. 选择处理结果：
   - **通过**：认定值计入完成值；
   - **驳回**：必须填写具体、可执行的修改意见，学院修改后重新提交。
7. 对无需核减且已核验的多条记录，可勾选后使用 **批量通过**。

审核完成后，完成值、完成率、统计报表和大屏会自动更新。年度已锁定或计划已归档时不能审核。

## 七、指标调整操作

### 7.1 调整类型与适用范围

| 类型 | 用途 | 适用规则 |
| --- | --- | --- |
| 延期 | 将未完成量推到后续年度 | 主要用于增量累计型；是否型可修改计划完成年 |
| 转移 | 将部分或全部未完成量转给其他学院 | 主要用于增量累计型，接收学院须具备承接资格 |
| 延期 + 转移 | 同时变更承接学院和完成年度 | 同时满足延期和转移规则 |
| 目标调整 | 修改已下发指标目标 | 仅管理员发起；其他口径需要变更时使用 |

延期不能超过规划末年；调整数量不能超过尚未完成量。历史任务、已归档计划和已锁定年度不能继续写入调整。

### 7.2 发起申请

管理员或建设方向负责人：

1. 进入 **调整申请与审批**，点击 **发起调整申请**。
2. 选择计划、指标或任务及调整类型。
3. 填写来源年度、目标年度、调整数量；转移类还需选择接收学院。
4. 填写调整原因并按需上传附件。
5. 点击 **试算对比**，核对调整前后目标、合计和冻结额度。
6. 试算通过后提交申请。

试算只是预览，不会修改正式目标；审批全部通过后调整才生效。

### 7.3 审批与确认

审批顺序为：

1. **建设方向负责人初审**；
2. **接收学院负责人确认**，仅转移类需要；
3. **校级负责人审批**。

处理人进入 **调整申请与审批** 或待办消息，打开申请详情，核对快照、原因、附件和审批时间线后选择通过或驳回。驳回时必须填写意见，任一环节驳回即结束本次申请。

审批期间，申请涉及的数量会被冻结，不能重复申请。申请人可在允许撤回时撤回申请，撤回后释放冻结额度。

### 7.4 调整生效后检查

- 查看转出方、接收方及目标年度的新目标。
- 接收方原来没有该指标任务时，系统自动创建任务。
- 在详情中核对调整前后快照、审批记录和操作日志。
- 调整不会自动增加完成值，后续仍需按新目标填报和审核。

## 八、统计、大屏、待办与材料

### 8.1 统计报表

1. 进入 **统计报表**。
2. 核对当前计划，选择年度和统计维度。
3. 查看指标、学院、完成值、完成率和达成状态。
4. 点击指标可进入详情或页内明细，返回后保留原查询条件。
5. 需要线下分析时使用页面的 **导出** 功能。

占比型按“分子合计 ÷ 分母合计”计算，不能把学院百分比直接平均；增长率型应关注完成总量及系统计算的增长率。

### 8.2 可视化大屏

- 有权限的用户进入 **可视化大屏**，选择计划和年度。
- 查看整体完成率、年度进度、学院对比、指标完成情况、预警和最近动态。
- 大屏数据自动刷新，适合展示和全局跟踪，不替代填报与审核页面。

### 8.3 待办与消息

进入 **待办与消息** 查看待填报、待审核、待审批及结果通知。点击待办可进入对应业务页面；处理后数量自动更新。历史任务不会生成新的待办或提醒。

### 8.4 材料库

进入 **任务执行 → 材料库**：

- 可按计划、关键产出指标、学院、材料类型和关键词检索。
- 点击 **预览** 在线查看图片、PDF、视频和支持的 Office 文档；不支持预览的格式使用下载。
- 管理员和建设方向负责人可点击 **上传材料**，选择关联指标并上传文件；上传完成后还要点击 **完成上传并关联**。
- 学院负责人通过任务填报上传材料，只有审核通过后才会进入材料库。

详细格式、大小限制和断点续传说明见《材料库使用说明》。

## 九、指标详情、里程碑与操作日志

### 9.1 指标详情与甘特图

在指标总表或统计报表进入 **指标详情**，可查看指标定义、年度目标、学院任务、完成进度、提交材料、调整历史及相关日志。甘特图用于查看年度任务和里程碑；已下发年度的目标变更仍需走调整审批，不会因拖拽直接生效。

### 9.2 操作日志

1. 进入 **操作日志**。
2. 按时间、学院、操作类型、操作人或指标筛选。
3. 展开一条日志，查看：
   - **操作摘要**：具体做了什么；
   - **具体变更**：字段、变更前内容和变更后内容；
   - **操作内容**：创建、删除、批量任务等明细；
   - **原因**：解锁、调整等敏感操作的说明。
4. 需要留存时按权限导出日志。

日志只能追加，不能修改或删除。

## 十、常见问题

### 为什么登录后看不到某个计划？

- 建设方向负责人只能看到本人负责指标关联的计划；
- 学院负责人只接触本学院任务关联的数据；
- 纯学院负责人账号首页直接是学院工作台；
- 如刚调整负责人，刷新或重新登录后再核对。

### 为什么学院看不到任务或没有填报按钮？

依次检查：任务是否已下发、任务是否属于本学院、是否为当前自然年、年度是否锁定、计划是否归档、任务是否为只读历史或已全部转出，以及是否存在审核中的填报。

### 为什么填报后完成率没有变化？

填报保存草稿或提交审核都不会直接计入完成值，必须审核通过。若审核已通过仍显示异常，先刷新并核对当前计划、年度和统计口径。

### 为什么材料库找不到刚上传的学院材料？

学院填报材料必须审核通过后才会进入材料库。材料库直传文件还必须完成“关联指标”操作，单纯上传成功不代表已入库。

### 为什么不能直接修改已下发目标？

为防止执行口径被无痕改变，已下发目标必须通过调整审批。追加新学院可在任务分解中单独保存和下发，但不能借此修改已有学院任务。

### 为什么年度核算或五年核算不能执行？

- 年度核算前需处理完待审核填报，并确认年度未锁定、计划未归档；
- 五年核算需规划期已结束且所有年度均已核算锁定。

### 页面提示“数据已被修改”怎么办？

不要连续重复提交。刷新页面，核对最新版本和他人修改内容，再重新编辑或审批。

## 十一、各角色操作检查清单

### 平台管理员

- [ ] 执行单元、用户、角色、负责人配置正确
- [ ] 计划周期、基线年和核算截止日正确
- [ ] 指标口径、目标、材料要求及方向归属正确
- [ ] 学院分工与负责人完整，下发校验通过
- [ ] 待审核填报已处理，再执行年度核算
- [ ] 五年核算和归档前已完成最终核对

### 建设方向负责人

- [ ] 只维护本人负责的指标和任务
- [ ] 下发前核对学院目标、负责人和材料要求
- [ ] 审核时查看原始材料，核减或驳回写明意见
- [ ] 调整申请先进行试算和守恒核对

### 学院项目负责人

- [ ] 只填报当前自然年和本学院任务
- [ ] 按统计口径填写新增量、总量或分子分母
- [ ] 上传完整、清晰、可核验的佐证材料
- [ ] 提交后关注审核结果，驳回后按意见修改
- [ ] 收到转入任务时及时确认或说明拒绝原因

### 校级负责人

- [ ] 通过统计报表和大屏掌握整体进度
- [ ] 审批调整时核对原因、快照、接收意见和目标守恒
- [ ] 对未达标、滞后和异常调整及时督促处理
