# 指标总表甘特图功能验证报告

日期：2026-10-31  
范围：全计划甘特图、单 A 指标甘特图、聚合接口、任务依赖、关键路径及拖拽交互。

## 1. 根因与修复结论

| 维度 | 发现的问题 | 修复 |
| --- | --- | --- |
| 数据加载 | 学院角色访问 A 趋势被 20005 拒绝，前端将异常静默转成空数据；完整任务需要逐 A/逐 B 请求 | 新增 `/plans/{planId}/gantt` 常量批次聚合接口；按角色裁剪，失败显示错误与重试，不再伪装空态 |
| 渲染配置 | 新虚拟组件首次挂载未立即触发 render；全量画布随任务数增长；虚拟窗口 `min-height:100%` 导致滚动高度持续增加 | 增加立即渲染；只绘制可视行和缓冲行；移除错误最小高度并增加滚动高度稳定断言 |
| 依赖兼容 | Vue 3.5、TypeScript、ECharts 6.1 与 Playwright 版本本身兼容，并非空白根因 | 继续使用 ECharts custom series，补充真实 canvas 和四引擎测试，不新增不必要依赖 |
| 数据格式 | RATIO 趋势缺分子分母；任务无完整全年度批量读模型；无依赖和关键路径数据 | 补齐趋势 RATIO 字段；统一年度节点 DTO；新增 FS 依赖、环检测和 CPM 结果 |

- 指标总表新增“计划甘特图”，指标详情展示该 A 全部可见 B；历史 A+ 归集到 A，每个 B 只计算一次。

- 时间轴放大、缩小、全规划期及拖动；节点搜索、展开/收起、悬浮详情和移动端点击详情。
- 进行中、达标、未达标、待审核、调整/延期、未来/无数据六类状态色；关键路径红色加粗，不覆盖状态色。
- 依赖创建/删除、数据范围、同计划、幂等、乐观锁、历史/归档只读、重复和环检测。
- 里程碑拖拽经确认后携带 version 保存；INCREMENT/BOOLEAN 年度段拖拽只预填延期申请，继续执行试算、申请和审批，不直接修改目标。
- 千级 DOM/ECharts 虚拟窗口、滚动/缩放/resize 合帧；加载、空态、无权限和请求异常分别展示。

## 6. 验收边界

- Playwright WebKit 已通过，可作为 Safari 兼容预检；当前 Windows 环境不能宣称完成真实 macOS Safari / iOS 飞书验收，需在目标设备补一轮触控和字体检查。
- 任务排期精度为年度，不虚构月内起止日期；季度/月缩放只改变时间轴观察精度。
- 第一版依赖为 FS，不支持 SS/FF/SF、跨计划依赖或自动重排目标。
- 真实示例任务存在相同年度区间时，依赖返回 `YEAR_CONFLICT` 属于预期提示；零时差关键路径算法、多个连通分量和多关键路径已由后端单元测试覆盖。
