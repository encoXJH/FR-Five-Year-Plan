# 安全自查清单

> 阶段 8 收尾输出。核查范围：全部按 ID 访问接口的数据范围校验、认证授权、敏感操作、审计完整性、密钥与配置、限流、文件与集成安全。核查日期：2026-10-24。

## 1. 数据范围（PRD 第 10 章：每个按 ID 访问的接口必须在服务端校验，越权 20005）

| 模块 | 校验落点 | 覆盖情况 |
| --- | --- | --- |
| 任务 task | TaskService：列表按角色过滤（isAll/isUnit/isOwner）；详情/接收 `canAccessUnit`；负责人维度按 ownedIndicatorIds | ✅ |
| 分解 allocation | AllocationService：查看/保存均 `canAccessIndicatorOwner(effectiveOwnerOf)` | ✅ |
| 填报 submission | SubmissionService：创建/提交/撤回按任务单元；查询按 unitId==user.unitId 过滤 | ✅ |
| 审核 review | ReviewService：待审列表非全校角色强制 owner 范围；审核操作校验指标有效负责人 | ✅ |
| 指标 indicator | IndicatorService：树/详情/修改/删除/目标/导入均 `canAccessIndicatorOwner`；owner 范围强制注入 ownerId 过滤 | ✅ |
| 手工认定 manual-value | ManualValueService：`canAccessIndicatorOwner` + indicator:edit | ✅ |
| 调整 adjustment | AdjustmentService：详情（申请人/全校/相关单元/相关指标负责人）、撤回（仅申请人）、列表按范围过滤、审批按环节处理人 | ✅ |
| 里程碑 milestone / 待补做 makeup | MilestoneService 指标负责人 / 任务单元；MakeupService `canAccessUnit` | ✅ |
| 统计 stats | overview/tree 按数据范围过滤后重算；trend 仅全校角色与指标负责人；by-unit/by-direction 为全校聚合（PRD Q12） | ✅ |
| 大屏 screen | screen:view 仅管理员/校领导（天然全校）；缓存无用户维度 | ✅ |
| 导出 export | 创建时固化 scopeOwner，任务结果按创建人数据范围生成；下载地址签名过期 | ✅ |
| 文件 file | 预览/下载按业务权限（材料随填报/调整数据范围）；raw 签名地址有时效 | ✅ |
| 消息 notification | 仅本人消息可查/已读（越权 20005） | ✅ |
| 审计日志 audit-logs | audit-log:view 权限码；查询条件不放大范围（operatorId/unitId 为过滤而非授权） | ✅ |
| 系统管理 | system:manage 全组（单元/专业群/用户/字典/参数）；用户停用不能停当前管理员 | ✅ |

**结论**：按 ID 访问的接口均在服务端做数据范围校验；E2E 各阶段均含越权用例（20004/20005）并通过。

## 2. 认证与授权

- JWT HS256：access 2h / refresh 7d，刷新旋转（revokedAt + replacedById）；logout 吊销 refreshToken。
- 密码 BCrypt；登录失败 5 次锁 15 分钟（参数可配）；重置密码/停用用户吊销全部 refreshToken（E2E 验证）。
- 方法级鉴权 @PreAuthorize 权限码 14+ 个；角色 ADMIN/LEADER/SCHOOL_OWNER/UNIT_OWNER 权限并集。
- 飞书免登按手机号/open_id 绑定，未配置时 20006，不影响账号密码登录（E2E 验证）。

## 3. 敏感操作 reason（API 约定第 10 章）

- 强制 reason：解锁年度、设置用户角色；E2E 验证缺 reason 被拒（400）。
- 调整申请理由 @NotBlank；驳回意见必填（60004）；核减认定值 ≤ 填报值（60005）。
- 人工认定说明写审计 reason。

## 4. 审计完整性

- @AuditLog AOP 覆盖全部写操作、导出、下载；登录 LOGIN 手工落库（不含密码/Token，含 requestId）。
- 角色变更、参数修改记录 before/after JSON；E2E 验证非空。
- 日志只追加：无任何修改/删除接口（E2E 验证 DELETE 404/10003）；数据库层建议（见部署手册）：应用账号仅授 INSERT/SELECT on audit_log，禁 UPDATE/DELETE。

## 5. 密钥与配置

- 全部敏感配置走环境变量（DB 密码、JWT 密钥、飞书 AppSecret、Encrypt Key）；.env.example 无真实值；.gitignore 排除 .env。
- 代码库无密钥明文（自查通过）。

## 6. 限流与幂等

- 登录 10 次/IP/分钟、导出 5 次/用户/分钟、普通 300 次/用户/分钟；超限 429+10006（E2E 验证登录档）。
- 幂等：API 约定 5.6 节接口全部校验 Idempotency-Key（两阶段占位 + 唯一键防并发 + 24h + 重放返回首次结果）。
- 乐观锁：可修改资源带 version（冲突 10005）。

## 7. 文件安全

- 上传按类别白名单（扩展名 + 大小，sys_setting 可配）；下载/预览走签名地址（过期失效）；本地存储路径隔离，StorageService 接口可换 MinIO。

## 8. 飞书集成安全

- 事件回调：sha256 验签 + AES 解密 + Verification Token 校验 + event_id 去重 + 异步处理 3s 内返回；签名失败 90002（fail closed，E2E 验证）。
- 卡片链接仅带页面路径，业务数据仍需登录态访问。

## 9. 前端与传输

- 菜单/按钮按 /auth/me permissions 显示，但不依赖前端做安全控制（服务端全部复核）。
- Axios 统一处理：Token 过期自动刷新重试一次；403/409/5xx 提示含 requestId。
- 生产部署 HTTPS（deploy/nginx-https.conf.example）；HSTS 建议在部署手册。

## 10. 生产配置

- Swagger 生产关闭（SWAGGER_ENABLED=false，已验证 404）。
- CORS 白名单按环境变量配置；错误响应不泄露堆栈（统一 {code,message,requestId}）。

## 已知限制（接受风险）

1. 限流为单机内存令牌桶，多实例部署需各实例各自计数（文档已注明）。
2. 大屏缓存 120s 单机内存，多实例各自缓存（数据允许短时延迟）。
3. 飞书 JSAPI 免登链路需真实飞书应用环境实测（本地无法验证 tt.requestAccess）。
