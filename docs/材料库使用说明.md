# 材料库 · 操作使用说明

材料库是工作平台中面向全校的跨学院材料统一管理板块，把各学院上传的工作材料集中存储，并按「关键产出指标」建立关联，支持管理员全局检索与在线预览。

- 菜单入口：左侧导航 **任务执行 → 材料库**（图标为文件夹）
- 页面路径：`/materials`
- 所需权限：`material:view`（查看）。管理员、校领导、校级项目负责人、学院项目负责人都可查看；上传需 `material:upload`（管理员、校级负责人、学院负责人）。

---

## 一、谁能看到哪些材料

| 角色 | 可见范围 | 可否上传 |
| --- | --- | --- |
| 平台管理员 | 全校所有学院材料 | ✅ |
| 校领导 | 全校所有学院材料（只读） | — |
| 校级项目负责人 | 本人负责的关键产出指标下的材料 | ✅ |
| 学院项目负责人 | 本学院（本执行单元）上传的材料 | ✅ |

越权访问会被服务端拦截并返回「没有数据权限」（20005），前端只做展示控制，不作为安全边界。

---

## 二、上传材料并关联关键产出指标

1. 点击页面右上角 **上传材料**。
2. 在弹窗中先选择 **关联关键产出指标**（支持输入指标编号或名称搜索，如 `A17`）。
3. 把文件拖入虚线框，或点击虚线框选择文件。支持多选、批量上传。
4. 观察每个文件的上传进度：
   - 单个文件 ≤ 20 MB 直传，进度条实时显示百分比；
   - 单个文件 > 20 MB 自动切换分片上传（5 MB/片），先计算 SHA-256 再传输；
   - 相同内容的文件会命中秒传，直接标记完成；
   - 上传中可 **暂停**，恢复时自动查询已传分片并 **断点续传**；
   - 每行可单独 **预览**、**下载**、**重试** 或 **删除**。
5. 全部文件显示「已完成」后，点击 **完成上传并关联**。系统会写入材料与指标的关联关系，并把文件状态由临时（`TEMP`）置为已绑定（`BOUND`）。
6. 关联成功后弹窗关闭，列表自动刷新出现新材料。

校验规则（前端预校验 + 服务端二次校验，包括文件头/魔数）：

| 类型 | 扩展名 | 单个文件上限 |
| --- | --- | --- |
| 文档 | doc、docx、xls、xlsx、ppt、pptx、txt | 50 MB |
| PDF | pdf | 50 MB |
| 图片 | jpg、jpeg、png、gif、bmp、webp | 20 MB |
| 视频 | mp4、mov、avi、wmv | 500 MB |
| 压缩包 | zip、rar（不支持在线预览） | 200 MB |

不合规的文件会在上传列表中直接显示红色错误行（格式不支持 80001 / 超过大小上限 80002），不会发起上传。

## 三、按关键产出指标检索材料

页面顶部为筛选区，支持四种条件的组合查询，任意条件变更即自动查询：

| 筛选条件 | 说明 |
| --- | --- |
| **关键产出指标** | 以指标为关键词精准检索，返回所有学院上传的与该指标对应的全部佐证材料 |
| **所属学院** | 按执行单元筛选（学院负责人账号不显示此项，因其只能看本学院） |
| **材料类型** | 文档 / PDF / 图片 / 视频 / 压缩包 |
| **关键词** | 匹配材料文件名，或指标编号与名称，回车即查询 |

- 列表中直接展示关联指标、所属学院、类型、大小、上传人、上传时间等元数据。
- 点击 **重置** 清空全部条件。
- 底部分页默认每页 10 条，可切换 10 / 20 / 50 条。

---

## 四、在线预览与下载

在材料行点击 **预览**，右侧滑出预览抽屉，无需下载即可查看：

- **图片**：直接渲染，支持浏览器缩放（Ctrl + 滚轮 / 双指）；
- **PDF**：内嵌阅读器，支持翻页、页码跳转与缩放；
- **视频**：内置播放器，支持播放、暂停、进度拖拽；
- **Office 文档（doc/xls/ppt）**：需服务端配置 kkFileView（环境变量 `app.file.kkfileview-url`）。未配置时提示下载后查看；
- **压缩包**：不支持在线预览，使用 **下载**。

预览与下载均使用 10 分钟有效的签名地址，下载会写入审计日志。

## 五、常见问题

**Q：为什么上传完成后列表没有出现材料？**
需要点击「完成上传并关联」才会写入关联关系；仅上传成功的文件为临时状态，24 小时内未绑定会被自动清理。

**Q：为什么只能关联到部分指标？**
指标下拉只展示当前账号数据范围内可关联的关键产出指标。学院负责人只能关联本学院已承接任务所属的 A 类指标。

**Q：能否关联别人上传的材料？**
不能（管理员除外）。系统校验上传人身份，非本人上传的材料禁止绑定，返回「没有数据权限」。

**Q：大文件上传中断了怎么办？**
点击该行的 **继续/重试**，系统会查询服务端已接收的分片编号，从断点继续，不会重新传输已完成的分片。

**Q：历史旧数据（A+ 层级）的材料能否检索到？**
可以。检索结果统一归集到所属 A 类关键产出指标展示，历史材料不会被丢弃。
